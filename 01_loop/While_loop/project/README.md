# Mini Real Case — While Loop Projects

## 📌 Overview

This section contains small real-world projects built using `while loop`.

The purpose of these projects is to apply fundamental programming concepts into practical scenarios, especially:

- condition-based looping
- control flow
- input validation
- simple state management

There are two main projects in this folder:

```text
1.  Number Guessing Game
2. Simple ATM System
```

## 🎯 Purpose

These projects are created to:

- strengthen programming logic through real use cases
- build a developer mindset (not just writing code, but controlling flow)
- practice handling user input safely
- prepare a solid foundation before moving into more advanced fields like Web3 & Blockchain

## 🧠 Concepts Applied

These projects directly implement concepts learned from:

- `while loop` (core iteration logic)
- loop condition & termination
- `break` and `continue`
- input validation (`try-except`)
- state management (user interaction, menu system)
- decision making (`if-elif-else`)

## 🎮 Project 1 — Number Guessing Game

### 📖 Description

The program generates a secret number, and the user must guess it.

### 🔑 Rules

- The user inputs a number
- If the guess is wrong:
  - the program gives a hint (too high / too low)
- The loop continues until the correct number is guessed
- The program shows how many attempts were made

### 💡 Concepts Practiced

- loop repetition until condition is met
- dynamic condition checking
- input validation
- attempt counter
- control flow with `break`

## 🏦 Project 2 — Simple ATM System

### 📖 Description

A simple command-line ATM simulation where users can interact with a menu.

### 🔑 Rules

- User selects options from a menu:
  - check balance
  - deposit money
  - withdraw money
  - exit
- The system runs continuously until the user chooses to exit
- Input must be validated
- Balance updates based on user actions

### 💡 Concepts Practiced

- infinite loop (`while True`)
- menu-based control flow
- state management (balance changes)
- input validation
- conditional branching

## 🚀 How to Run

1. Make sure Python is installed
2. Open terminal in this folder
3. Run one of the project files:

```bash
python number_guessing_game.py

```
