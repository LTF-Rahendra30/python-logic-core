- `while loop`
- loop condition & termination
- infinite loop and how to prevent it
- state management inside loops
- `break`, `continue`, `pass`
- input validation
- retry logic
- simple state-based systems

## Insight

- A loop isn't just about repeating code, but about controlling when it should stop
- Small mistakes (like a missing variables update) can cause infinite loop
- The most important part of a `while loop` is the condition and state loops
