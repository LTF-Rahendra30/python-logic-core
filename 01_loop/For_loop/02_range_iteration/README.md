# Modul 02 Range & Index Iteration


**Tujuan:**  
- Paham `range(start, stop, step)`  
- Bedain loop berdasarkan *value* vs *index*  
- Mengerti efek *state mutation* (urutan eksekusi berpengaruh)  
- Latihan iterasi mundur & step ganjil/genap


## File di folder ini
- `01_basic_range.py` — contoh dasar `range()` (start/stop/step)  
- `02_iteration_range.py` — contoh pakai `range(len(...))` untuk akses index  
- `03_practice_range.py` — praktik: mutasi list forward, snapshot, reverse; disertai komentar langkah demi langkah
