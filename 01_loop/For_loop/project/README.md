# Simple Blockchain Ledger (Python)

## 📌 Overview

This project is a simple simulation of a blockchain transaction ledger using basic Python logic.

It is designed to demonstrate fundamental programming concepts such as:

- for loops
- range iteration
- enumerate usage
- nested loops
- algorithmic patterns (filtering, counting, finding max)

## 📊 Data Rules

This rule is the important part of the project.

- positive transaction : Like a income, for exemple: buying tokens or buying coins
- negative transaction : like a spending,for example: sell or send coins or tokens.Not an eror,however, It is a part of the system
- 0 : edge case, is a default transaction, not it included in the balance and not a valid transaction
- The balance is calculated by adding up all positive transactions

## 🎯 Purpose

This project is part of a learning journey to build strong logic and problem-solving skills before moving into real blockchain and Web3 development.

## ⚙️ Features

- Display all transactions
- Number each transaction using `enumerate`
- Filter valid transactions (e.g., positive values)
- Calculate total balance
- Find maximum transaction without using built-in `max()`
- Simulate simple blockchain blocks (nested loops)

## 🧠 Concepts Used

- Iteration over lists
- Index vs value
- Conditional logic inside loops
- Accumulator pattern (sum, counter)
- Nested loop for block simulation

## ▶️ How to Run

Make sure you have Python installed.

Run this command in your terminal:

```bash
python ledger.py
```
