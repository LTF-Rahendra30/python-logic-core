## 📖 Description of the Project File

### 1. Task Management App

The first project in this folder is a **Task Management App**.

This project is designed to simulate a simple task organizer where users can add, validate, display, update, and manage tasks using Python functions.

#### Why this project?

A Task Management App is a strong first project because it naturally combines multiple function-related concepts in one place. It helps demonstrate how functions can work together as a system instead of being used only as isolated examples.

#### What this project teaches

- How to compose functions so each function handles a specific responsibility
- How to manage variables using local and global scope correctly
- How to separate logic into pure functions and impure functions
- How to store and process tasks using lists and dictionaries
- How to control program flow with loops and conditionals

#### Core learning focus

This project is not only about making a task app. It is about understanding how function-based logic is built step by step.

By the end of this project, I should be able to understand how to:

- Validate input before processing data
- Organize code into reusable function blocks
- Keep logic readable and maintainable
- Use Python fundamentals to solve a real problem
