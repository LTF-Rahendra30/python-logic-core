# 💻 OOP (Object Oriented Programming) — Fundamental Programming Logic Core

## 📌 Overview

This section focuses on understanding Object-Oriented Programming (OOP) as a **core paradigm for structuring logic,managing state, and designing scalable systems**, not just as a Python-specific feature.


Rather than treating OOP as a Python-specific feature, this module emphasizes the fundamental ideas behind OOP, including how data and behavior are organized, how state is managed, and how systems can be designed using objects.

The goal is to move beyond syntax and develop a deeper understanding of programming logic and system thinking.

## 🎯 Learning Goals
- Understand the difference between **procedural and object-oriented programming**
- Learn how to model real-world problems using classes and objects
- Master the concept of state and how it changes over time
- Understand how methods operate on object state
- Learn how to **control and protect data using encapsulation**
- Build the ability to design small systems using OOP principles
- Develop strong reasoning skills about why and when to use OOP
- Build strong intuition for **abstraction, responsibility, and data flow**

 ## 📖 Description

***01_basic_class/**

Focuses on the fundamental structure of OOP:
- What is a class?
- What is an object (instance)?
- How __init__ works
- Difference between regular variables and instance attributes (self)

Goal: Understand how objects are created and how they hold data.

**02_state_and_method/**

Introduces the concept of state and behavior:

- Instance variables (self.attribute)
- Methods vs functions
- How state changes over time
- Interaction between multiple objects

Goal: Understand that programs are not just sequences of steps, but systems that manage changing state.

**03_encapsulation/**

Focuses on controlling access to internal state:

- Private attributes (_ and __)
- Getter and setter patterns
- Input validation inside methods
- Protecting object integrity

Goal: Learn how to control and secure data within objects.

## 🧠 Core Concepts Learned

- Encapsulation and Data Protection
- Responsibility in System Design
- Abstraction (when and why to use objects)
- Refactoring from procedural to object-oriented design
